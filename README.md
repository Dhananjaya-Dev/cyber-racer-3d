A high-octane, synthwave-inspired 3D endless highway driving experience built natively for modern web browsers using **HTML5**, **WebGL**, and **Three.js**. Maneuver through dense highway traffic, pick up energy shields and nitro canisters, inspect machines in an interactive 3D garage turntable, and survive as procedural difficulty scales with distance.

## ✨ Key Features

- **🏎️ 10 Playable Stylized Vehicles:**
  - Classic Auto Rickshaw, Compact SUV, Heavy Farming Tractor & Trolley, Intercity Passenger Bus, Heavy Cargo Lorry, High-Speed Sports Bike, Emergency Fire Truck, City Ambulance, Construction Excavator, and Mobile DJ Sound Truck.
- **🛠️ Interactive 3D Garage Showroom:**
  - 360-degree rotating vehicle inspection turntable.
  - Live vehicle telemetry spec sheets (Top Speed, Handling, Acceleration, and Armor).
- **⚡ Dynamic Progression & Physics Engine:**
  - Automated cruising speed scaling based on survival distance.
  - Realistic cornering tilt, steering bank, and dynamic wheel rotation physics.
- **🛡️ Collectibles & Tactical Power-Ups:**
  - **Turbo Boost:** High-speed nitro surge with camera FOV warp effects.
  - **Holo-Shield:** Protective spherical energy barrier preventing traffic collisions.
  - **Energy Orbs:** Combo multiplier point accelerators.
- **🌆 Retro Cyberpunk Aesthetics:**
  - Procedurally generated illuminated neon skyscrapers, dynamic highway billboards, infinite synthwave grid horizon, and particle motion trails.
- **🔊 Procedural Web Audio API:**
  - Real-time synthesizer engine roar, nitro wooshes, collision impacts, and pickup chimes without external audio asset downloads.
- **📱 Responsive Dual Controls:**
  - Full support for on-screen touch buttons (mobile-friendly) and physical keyboard inputs.

## 🕹️ Controls Guide

| Action | Keyboard Key | On-Screen HUD Button |
| :--- | :--- | :--- |
| **Steer Left** | `A` or `Left Arrow` | `LEFT` Button |
| **Steer Right** | `D` or `Right Arrow` | `RIGHT` Button |
| **Push Turbo / Nitro** | `W` or `Up Arrow` or `Space` | `PUSH` Button |
| **Brake / Decelerate** | `S` or `Down Arrow` | `BRAKE` Button |
| **Pause / Resume** | `P` or `Escape` | `PAUSE` Button |
